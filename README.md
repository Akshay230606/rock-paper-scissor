# Rock Paper Scissors 🎮

A simple **Rock Paper Scissors** game built with **HTML** and **JavaScript** as part of **The Odin Project Foundations** curriculum.

The game runs entirely in the browser console and allows the user to play **5 rounds** against the computer.

---

## Features

- 🎲 Random computer choice
- 👤 User input using `prompt()`
- 🏆 Five-round gameplay
- 📊 Automatic score tracking
- 🎯 Final winner announcement
- 🔤 Case-insensitive user input

---

## Technologies Used

- HTML5
- JavaScript (ES6)

---

## How to Play

1. Open `index.html` in your browser.
2. Open the browser's Developer Console (`F12` → Console).
3. Enter one of the following when prompted:
   - `rock`
   - `paper`
   - `scissors`
4. Play all 5 rounds.
5. The final winner and scores will be displayed in the console.

## Game Logic

- Rock defeats Scissors
- Scissors defeats Paper
- Paper defeats Rock
- Matching choices result in a tie

The game repeats for **5 rounds**, keeps track of both player and computer scores, and declares the winner at the end.
